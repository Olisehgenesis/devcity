# antislop audit 001

Date: 2026-10-18
Mode: after (session override)
Scope: the live city app as it stands in this repo. Map, filters, drops and claims, events, places, people, city hub, feed, scan, inbox, wallet, profile, and the chrome around them.

Nothing below was changed. Pick the numbers to fix.

## Findings

1. HIGH. R-27. Location is on in the app, but a slow or failed GPS reading is labeled "Location unavailable" and tells the person to turn location services on. `watchPosition` treats every error except permission denied as services being off, including a timeout. Claims stay blocked on that wrong message. Seen on the live drop card and the drop sheet.

2. HIGH. R-03. The map header puts search, city hub, notifications, Invite, the location pin, locate, and the profile photo in one row that does not wrap. On a phone those 44px controls crowd the title and hide each other. The user already hit this: search covers the icons.

3. HIGH. R-02. User-visible copy still uses an em dash. Empty map: "No live drops yet — press and hold, or double-press, the map to create one." Create-drop review: "Your balances are read live from {chain} — no new token is deployed."

4. HIGH. R-38. Leaderboard rows label every person "City explorer", including people whose username is real. Feed comments and the profile fallback use the same invented label when a handle is missing. That reads as a person, not as an empty field.

5. MEDIUM. R-09. "DEVCITY 26: Mumbai Edition" sits above "City map", on the loader, on the profile, and on the add-place sheet. Trending, Leaderboard, Notifications, and Create a drop repeat a "Mumbai · …" eyebrow the title already states. The owner asked for that edition line to come off.

6. MEDIUM. R-04. Sparkles is the icon for Trending, Leaderboard, Scan, search results, and token launch, with no written reason. The same Lucide stroke set is the default across map, feed, wallet, and sheets.

7. MEDIUM. R-04. Dex, the robot courier on the leaderboard, is a named robot illustration. The game direction uses it as a mascot. Keep it only if you want that mascot. Otherwise it is the default robot glyph.

8. MEDIUM. R-08. "Explore drop" and the claim button carry an arrow as decoration. The arrow does not say where the action goes.

9. LOW. R-15. The drop card button says "Explore drop". Explore is a generic call to action. The action is opening that drop.

## Checked, not filed

Map filters (Everything, Drops, People, Events, Places), create stall, create booth, create drop, feed composer, scan, inbox, wallet send and receive and swap, friends, and Self verification each open a real surface. They are not dead navigation.

The stories file still holds invented people and places (Genesis, Amina, Kai, Mara, Tobi, KICC, The Foundry). Nothing in the current UI opens that viewer, so it is not on screen. It becomes finding 4 if it is shown again.

Tap targets on the round header buttons and the bottom nav are 44px. A global focus ring exists. Those two checks did not fail on their own.

This pass read the source and the owner's last on-screen report. It did not click every control in a browser in this session.

## Follow-up

Fixed 1 through 9, with one keep.

1. A timed-out reading now says location is already on and offers another try. A missing position no longer says to turn location services on. The map watch uses a normal reading first, then one coarser retry.
2. Search and the notification bell are off the map header. Notifications open from the profile. The header stacks on a narrow screen.
3. The empty-map line, the create-drop note, and the missing-token error no longer use an em dash.
4. Leaderboard rows show the handle only. Missing feed names say Someone. A profile with no handle says Your profile.
5. The Mumbai Edition line and the Mumbai eyebrows are off the loader, map, profile, sheets, and the browser title.
6. Sparkles is no longer the icon for events, trending, the leaderboard, tips, scan, search events, or token launch.
7. Dex is off the empty leaderboard, trending, notifications, and suggestions. It stays on the game bar, where it is the product mascot.
8. Open drop and Claim no longer carry an arrow.
9. The drop card says Open drop.
